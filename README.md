Welcome to Catherine Royale, a restaurant website designed to showcase the brand and make it easier for customers to explore the restaurant and make reservations.

About the Website

Catherine Royale provides visitors with a simple way to discover the restaurant and access its reservation section.

Features

* Restaurant website and brand presentation
* Reservation section for customers
* Online reservation request form
* Responsive website experience
